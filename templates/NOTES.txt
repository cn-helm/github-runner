Runner deployment: {{ include "github-runner.name" . }}

Check startup and registration:
  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "github-runner.name" . }} -f

Confirm the runner is Online in GitHub Settings > Actions > Runners.
Pod Running/Ready alone does not confirm GitHub connectivity.

Both containers use the public Ubuntu Noble image. No image build is required.
Check dependency initialization with:
  kubectl logs -n {{ .Release.Namespace }} deployment/{{ include "github-runner.name" . }} -c dependencies
For first startup, enter GITHUB_RUNNER_TOKEN in Rancher Customize
(github.token), or use the existing registration Secret.
Registration is reused from the PVC on restart.
